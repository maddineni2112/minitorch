# MiniTorch

**Timeline:** April 2025  
**Category:** Main project

MiniTorch is a from-scratch educational deep-learning framework implemented in Python. The work develops tensor operations, automatic differentiation, module abstractions, and test-driven numerical behavior across the course modules.

## Stack

Python, NumPy, PyTorch, Pytest, Hypothesis, Streamlit, Plotly, and NetworkX.

## Repository contents

- `src/` — MiniTorch module implementations and project scripts.
- `tests/` — copied module tests where redistribution is appropriate.
- `reports/` — project documentation.
- `data/README.md` — statement that the project is code-only and has no raw dataset.

Run the module-specific setup instructions and tests from the included environment file. The project does not require a raw dataset.
